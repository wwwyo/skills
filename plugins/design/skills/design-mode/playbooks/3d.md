# 3D

three.js・React Three Fiber で 3D シーンを作る・直す。

1. **土台を作る。** **threejs-fundamentals** で scene・camera・renderer・loop・resize・後片付けを決める。React なら **threejs-react-three-fiber**
2. **形と読み込み。** 形を作るなら **threejs-geometry**。model・texture を読むなら **threejs-loaders**、重い glTF は **threejs-asset-pipeline** で圧縮する
3. **見た目。** **threejs-materials**・**threejs-lighting**・**threejs-textures**、独自の効果は **threejs-shaders**、画面全体の効果は **threejs-postprocessing**
4. **動きと操作。** **threejs-animation**・**threejs-interaction**
5. **重いとき。** **threejs-performance** で draw call・fill rate・メモリを測ってから直す
6. **見て確かめる。** スクリーンショットか録画で確かめる。WebGL と WebGPU の両方を狙うなら両方で見る
