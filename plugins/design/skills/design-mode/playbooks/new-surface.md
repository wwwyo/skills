# New surface

新しい画面・サイト・視覚システムを作る。

1. **token を決める。** repo root に `design.md` が無ければ **design-md** で作る。参考にするサイトや Figma の指定があれば抽出、無ければ 0 から設計する
2. **方向を決める。** **unslop** の「プロダクトから方向を見つける」手順で、この画面の性格を 1〜2 文で決める。紫のグラデーション・glow・絵文字ラベルなどの AI っぽい定番に寄せない
3. **部品を選ぶ。** 自作する前に **pick-ui-library** で primitive・toast・drawer などの定番を確かめる
4. **実装する。** コードは mode の Feature playbook に従う。token は `design.md` から引く
5. **壊してみる。** **break-ui** で長い名前・空・巨大な数・非ラテン文字を流し、崩れた箇所を直す
6. **見て確かめる。** デスクトップとモバイル幅のスクリーンショットを撮り、2 の方向と合っているかを見る
