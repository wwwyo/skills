# Polish

既存 UI の手直し。AI が作ったような見た目を、性格のあるデザインにする。

1. **方向を決める。** **unslop** を読み、プロダクトから方向を決める
2. **unslop の順で直す。** 余白 → 色 → icon → 文言 → 文字 → layout → 細部 → 動き。前の段が決まる前に後ろの段をいじらない。色と文字は `design.md` の token に寄せる（無ければ **design-md**）
3. **細部を詰める。** **emil-design-eng** で押下・hover の状態、popover の起点、tooltip の間合い、transition と keyframe の使い分けを見る
4. **壊してみる。** **break-ui** で最悪のデータを流す
5. **前後を見比べる。** 直す前と後のスクリーンショットを並べて報告する
