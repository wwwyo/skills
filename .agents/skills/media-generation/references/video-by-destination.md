# 動画の流す場所 — 宣伝・解説・発表の中で流す

入口は [SKILL.md](../SKILL.md) の「動画は流す場所から決める」節。Video A・B のどちらで作るときも、台本・構成を書く前にこのファイルで通りを決める。

動画は少なくとも三通りに分かれ、通りごとに正解が逆になることがある。分かれ目は中身ではなく、**どこで流れるか**と**見る人が自分で止められるか**。依頼に流す場所が書かれていなければ、作り始める前に一度だけ聞く。

出典: 西尾泰和「動画の作り方 ― 三通りの動画と、それぞれのノウハウ」（https://www.youtube.com/watch?v=IDkRFwiFXFI 、2026-11 時点）。各項目は動画内の主張で、原典（各社広告ガイド・WCAG 2.2・Netflix 字幕ガイド・論文）は動画の概要欄にある。背景の整理は wwwyo/me の [wiki/tech/video-making-by-destination.md](https://github.com/wwwyo/me/blob/main/wiki/tech/video-making-by-destination.md)。

## 通りを決める

| 通り | 流れる場所 | 見る人は止められるか | 勝負どころ |
| --- | --- | --- | --- |
| 宣伝 | SNS のフィード・ストア | 止めない（流し見） | 指が止まるか |
| 解説 | 自分で見に来る（YouTube・記事埋め込み） | 止める・戻せる | 理解が進むか |
| 発表の中で流す | スライドの途中 | 止められない | 一つの概念が伝わるか |

宣伝の形にすると技術の詳細は伝わらない。広めたいのと理解させたいのが両方あるなら、**別の動画を2本作る**。

## 作り方の割り振り

- 文字・数字・図は**コードで描く**（Video B）。生成モデルは画面の文字がまだ正確に出ない
- 作品やアプリの紹介は**実物（画面収録・撮影）を土台**にする。切り出し・重ねは ffmpeg か Video B に任せる
- 丸ごと生成（Video A）は、中身を見せない場面のつなぎ・雰囲気のカットにだけ使う

## 宣伝

- [ ] 最初の3〜5秒に一番大事なものを置いた
- [ ] 出す場所の音の前提を決めた（X や YouTube のホームは音なしで流れる → 字幕だけで通じるように作る。音を主役にするなら音ありが前提の場所に出す）
- [ ] 動きを長く止めず、数秒ごとに新しいことが起きる
- [ ] 場面の切り替えを音楽の拍に揃えた
- [ ] 実物を誤解させない（App Store のプレビュー動画はアプリ自身の画面収録に限る）
- [ ] 点滅は1秒に3回まで、赤い点滅を使っていない

## 解説

- [ ] ナレーションの台本を先に書き、場面は声の区切りで切り替える（尺は台本で決まる）
- [ ] 尺は日本語で1秒に6〜7文字＋文の間で見積もった。長すぎたら早く読ませず台本を削った
- [ ] 「なぜ」を先に、最初の30秒で見る理由を渡した
- [ ] よくある誤解を言ってから訂正する構成を検討した
- [ ] 動きは「いま話しているものを指す」か「物が変わる様子を見せる」ためだけ。飾りの動きは入れない
- [ ] 合成音声は文字起こしして台本と照合し、読みは辞書で直した。最後の確認は人に聞いてもらう（agent は音声を聞けない。手順は [audio-generation.md](audio-generation.md)）

## 発表の中で流す

- [ ] 1本に1つの概念だけ、20秒〜1分
- [ ] 文字は読み終わるまで出している（日本語字幕の目安は1行13文字まで）
- [ ] 声は話し手か動画のどちらか一方（話し手が語るなら動画は無音）
- [ ] 待ち時間・処理中を黙って映さず、何が起きているかの説明に変えた
- [ ] 発表者が流す前に「いまから何が映るか」を一言いう前提で台本に入れた
- [ ] 書き出しは H.264＋AAC の MP4（PowerPoint・Keynote・Google スライドで流せる）

## 正解が逆になるところ

| 観点 | 宣伝 | 解説 | 発表の中で流す |
| --- | --- | --- | --- |
| 場面の切り替えの基準 | 音楽の拍 | ナレーションの区切り | 見る人が読み終えるまで待つ |
| 動き | 長く止めない | 飾りの動きはしない | 1つの概念に絞る |
| 音 | 場所次第（音なしも多い） | ナレーションが主役 | 話し手か動画の一方 |

できた動画が合格かどうかは、最後に見る人が決める。書き出したら、流す場所と同じ条件（音なし・止めずに一度だけ等）で見直す。
