# Motion audit

既存の動きを棚卸しする。目的に合う skill を 1 つ選び、混ぜない。

- 動きが足りない、どこを動かせるか知りたい → **find-animation-opportunities**（読むだけ。値まで提案する）
- 動きが多すぎる、遅く感じる → **remove-animations**（削るだけ。足さない）
- 全体を直したい、計画が欲しい → **improve-animations**（読むだけ。優先順位つきの計画を出す）
- 特定の動きの出来を判定したい → **review-animations**

計画だけを出す skill の結果を実装するときは、Motion playbook に移る。
