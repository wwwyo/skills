# unslop の適応意図

UI の作り直しは unslop に一本化する（2026-11-11、hallmark から乗り換え）。同じ叩き台を両 skill で作り直す比較で、unslop の方が「その製品らしい主役」を作り、ユーザーが見たくなる画面になった。原本の方向性5行・9パス・主役を1か所に集める考え方はそのまま保つ。

一方、比較では2回とも題材から弁柄・生成りに寄り、色が skill の癖で決まっていた。色と書体は skill がその場で創作せず、repo root の `design.md`（`design-md` skill が書く共有書式）を正本として従わせる。`design.md` があるときは色・書体・余白の値を変えず、方向性は Character・Moments・Signature をその中で決める。値が足りないときは創作せず報告する。

原本の検証は描画して見比べるだけで、幅ごとの確認が無い。ユーザーのメイン端末は Android なので、320・375・414px で横スクロール・2行に折れるクリック可能な文字・11px 未満の文字・はみ出しが無いことを確かめてから報告させる。

データの捏造禁止は足さない（ユーザー判断）。原本の「Do not invent features, claims or data」で足り、実データがあればそれを使う前提でよい。
